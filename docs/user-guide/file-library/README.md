# File Library

Last updated: 2026-10-31

The File Library is the second tab of the File Manager. It lists files from
every chat session, not only the one that is open. The list is a folder
explorer so a long library does not arrive as one flat page of cards.

## Opening it

Open the File Manager from the header, then choose **File Library**. The
**Session Files** tab is unchanged and still shows only the current chat.

## Folders

The folders down the side are views of the same library:

| Folder | What it shows |
| --- | --- |
| All files | Every file you can see |
| Uploads | Files you uploaded |
| Generated | Files a tool created |
| Documents, Images, Data, Code, Other | Files grouped by type |

The breadcrumb above the list shows where you are. Choose **File Library** in
the breadcrumb to return to every file.

Search still matches the file name. Sort still orders the rows you are looking
at by date, name, or size. Download, delete, and **Add to session** work the
same way they did on the flat list.

## Long libraries

The library loads one page at a time (50 files). When there are more, use
**Previous** and **Next** under the list. The heading shows the total, and the
line under it shows which rows this page holds.

On a single page, **Delete All** deletes every file in view and **Delete
Filtered** deletes the files that match the current folder or search. When the
library spans more than one page, the same button is **Delete Page** and
deletes only the rows on the page you are looking at.
