Team prompt library: save versioned system prompts, share them with Atlas groups (view/use) or named people (use, edit, manage), fork them, and pick a specific or latest version in chat. Shared prompts are resolved and authorized server-side on every turn, each conversation keeps the exact version it ran with, and every change is audited (`/api/prompts`, migration `004`). Concurrent edits and sharing changes are guarded by revisions (HTTP 409 instead of lost updates), and an unavailable pinned prompt can be cleared by the conversation owner (`DELETE /api/prompts/pins/{conversation_id}`). Clearing a pin also applies to sessions that already have the conversation open, a conversation that fails to load is refused rather than run on another prompt, save-then-publish publishes exactly the saved draft, and a turn naming both a team prompt and a custom prompt or persona is rejected.
