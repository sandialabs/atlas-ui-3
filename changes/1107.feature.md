The Help page can now show documentation that is hosted outside Atlas. Set `HELP_DISPLAY_MODE=remote_markdown` with `HELP_CONTENT_URL` to have Atlas fetch the Markdown server-side and render it in the existing Help page (images are resolved against the hosted document and served through Atlas, so no cross-origin requests are made and the content security policy still applies). Set `HELP_DISPLAY_MODE=external_link` to have the Help button open the documentation site in a new tab instead, without fetching anything. The default `local` mode is unchanged: the Help page still shows the local `help.md`, and the Admin editor still writes it. Hosted documents are cached (five minutes by default, refreshed with a conditional request) and the last known good copy is served when the documentation host is unreachable; a missing or unusable URL is reported as a configuration error and falls back to the local Help content instead of leaving a broken Help button. See `docs/admin/help-config.md`.
