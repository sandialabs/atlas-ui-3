Browser-stored state is now kept per signed-in user, so on a shared browser the next account no longer sees earlier accounts' locally saved conversations or starts on their selected model, compliance filter or splash-screen acceptance; a saved team-gateway model is also dropped on load when the user is no longer in that team. Conversations saved locally before this change have no recorded owner and are no longer listed (they stay in the browser's storage), and each user picks their model and accepts the splash screen once more after upgrading.
