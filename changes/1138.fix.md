Context compaction no longer reports a bare "the model returned an empty checkpoint". A summarization reply with no text is retried once with a larger output-token budget and deterministic sampling, and if it is still empty the failure says which of the three causes it was: the model wrote nothing, it spent its whole output budget first (what a reasoning model does when reasoning drains the cap), or the provider call failed. The log line carries the resolved model and provider, finish reason, and prompt/completion/reasoning token counts -- never content, reasoning text or a request body. A failed compaction still leaves the conversation history and the agent run's transcript exactly as they were.
