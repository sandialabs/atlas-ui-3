Added reproducible load and scale profiles for multi-replica deployments (`bash test/load_tests.sh <profile>`, issue #1129): WebSocket capacity, reconnect storms including a replica crash, concurrent agent runs, and OIDC login with RFC 8693 token exchange, against real replicas sharing Redis and PostgreSQL with mock LLM and IdP services. Each run reports p50/p95/p99 latency, errors, active runs, connection counts and replica/Redis/PostgreSQL resource usage; see `docs/developer/load-testing.md`.
