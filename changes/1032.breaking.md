Models, MCP servers and RAG sources now declare the data classifications they may receive with `allowed_data_classifications`, and the server refuses any chat turn whose selected compliance level is not listed by the model, the servers behind its tools or its data sources. Components with no declaration are unavailable in classified sessions, and `allowed_with` no longer grants access across levels; a legacy `compliance_level` is still read as a one-element list (see docs/admin/compliance.md for migration).
