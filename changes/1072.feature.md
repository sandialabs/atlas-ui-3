## [Unreleased] - Enhance classificationLock with state-specific guidance for locked conversations

The `classificationLock` function in `frontend/src/utils/conversationClassification.js` now provides state-specific guidance when a conversation is locked to its compliance level. Previously, all locked conversation states received the same generic guidance. Now each state (unclassified, legacy, invalid) gets tailored guidance that explains why the conversation is locked and what the user should do next.

- **unclassified**: Conversation was saved with no compliance level and is locked. Start a new conversation at a specific compliance level to continue working.
- **legacy**: Conversation was saved before compliance levels were recorded and is locked. Start a new conversation to add a compliance level.
- **invalid**: Conversation has an unreadable compliance level and is locked. Start a new conversation.

This improves the user experience by providing clearer guidance about compliance level locking.
