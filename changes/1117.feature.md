Compliance levels can now define an optional, presentation-only `display_name` in `compliance-levels.json` (for example `CUI (Restricted)` for the key `CUI_no_ECI_no_ITAR_no_PII`), and ATLAS renders that friendly label everywhere a level is shown: the header security selector, model/MCP/data-source badges, the classification banner (after a banner's own `label`), conversation history rows, and server refusal and warning messages. Canonical names stay the identifiers for policies, aliases, APIs and saved records; levels without a `display_name` render their name exactly as before.
