Added optional dictation and read-aloud: a microphone button in the message box transcribes speech into an editable draft, and a speaker button on assistant replies plays them with pause, stop and speed controls. Each is off by default and is configured on its own OpenAI-compatible audio endpoint (`FEATURE_AUDIO_STT_ENABLED` / `FEATURE_AUDIO_TTS_ENABLED` and the `AUDIO_STT_*` / `AUDIO_TTS_*` settings); users can show or hide each button in Settings. See `docs/admin/audio-stt-tts.md`.
