Dictation and read-aloud can now each use their own provider adapter, chosen with `AUDIO_STT_PROVIDER` / `AUDIO_TTS_PROVIDER`: in-process LiteLLM (`litellm`: OpenAI, ElevenLabs, Groq, Deepgram, Mistral, Vertex AI and more, no proxy server), Google Gemini (`gemini`, using `GOOGLE_API_KEY`), native ElevenLabs (`elevenlabs`), or Chat Completions audio models such as `gpt-audio-1.5` (`openai_chat_audio`). The new optional `AUDIO_TTS_INSTRUCTIONS` and `AUDIO_TTS_SPEED` settings are passed where the provider supports them. The default `openai_compatible` provider is unchanged. See `docs/admin/audio-stt-tts.md`.
