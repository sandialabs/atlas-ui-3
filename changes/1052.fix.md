Docker Compose no longer requires credentials for storage backends you do not use: bundled MinIO and PostgreSQL moved to opt-in Compose files (`docker-compose.minio.yml`, `docker-compose.postgres.yml`), external S3 needs no `MINIO_ROOT_PASSWORD`, DuckDB needs no `POSTGRES_PASSWORD`, and the bundled MinIO reuses `S3_ACCESS_KEY`/`S3_SECRET_KEY` as its root credentials.

  Operators upgrading a single-file stack: plain `docker compose up` now starts only Atlas — add `-f docker-compose.minio.yml` and/or `-f docker-compose.postgres.yml` for the bundled services. `MINIO_ROOT_USER`/`MINIO_ROOT_PASSWORD` are no longer read; to keep an existing `minio-data` volume, set `S3_ACCESS_KEY` to the old `MINIO_ROOT_USER` (default `atlas-minio`), `S3_SECRET_KEY` to the old `MINIO_ROOT_PASSWORD`, and `S3_ENDPOINT=http://minio:9000`.
