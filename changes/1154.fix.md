Phones (narrower than 640px) now get a mobile chat composer instead of the desktop one squeezed down. The message box uses the full width, an agent run shows a single Stop that stays in view, the model, tools, prompt and context controls fit on one row, and the feedback button no longer takes a column beside the composer. Touch screens in landscape also float the feedback button above the composer instead of reserving a column for it. Wider screens otherwise keep the desktop layout.
