Phones (narrower than 640px) now get a mobile chat composer instead of the desktop one squeezed down. The message box uses the full width, an agent run shows a single Stop that stays in view, the model, tools, prompt and context controls fit on one row, and the feedback button no longer takes a column beside the composer. At every width the app now keeps clear of notches and the home indicator on devices that have them; the desktop layout is otherwise unchanged.
