Tool and settings controls are clearer: model capability icons now show a picture for image input and slash out unsupported capabilities instead of only dimming them, and the header Tools and Settings button uses a gear with a wrench badge so it no longer looks like the tool picker. Auto-Approve Tool Calls now explains that off (the default) asks before tool calls run and that auto-approve never answers tools an administrator has marked as requiring approval, and each approval row says why it is asking. Tool chips, toggles and approval buttons also report their on/off and expanded state to assistive tech and show a keyboard focus ring.
