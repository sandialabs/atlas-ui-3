Chat history requires SQLAlchemy 2.1+ (installs pinned to SQLAlchemy 2.0 must upgrade or stay on an earlier release) and connects with the psycopg 3 driver: bare `postgresql://` URLs — previously psycopg2 under SQLAlchemy 2.0 lockfile installs — are normalized to `postgresql+psycopg://` for both the app and Alembic, while explicit `postgresql+psycopg2://` URLs keep working. Behind transaction-mode PgBouncer, use one of: `CHAT_HISTORY_DB_DISABLE_POOLING=true` (the chat-history engine then keeps psycopg 3 statements unnamed), PgBouncer 1.21+ with `max_prepared_statements` set, or `session` pooling mode; run `alembic upgrade` against the database directly, not through a transaction pooler.
