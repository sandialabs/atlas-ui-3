Chat history requires SQLAlchemy 2.1+ (installs pinned to SQLAlchemy 2.0 must upgrade or stay on an earlier release) and connects with the psycopg 3 driver: bare `postgresql://` URLs — previously psycopg2 under SQLAlchemy 2.0 lockfile installs — are normalized to `postgresql+psycopg://` for both the app and Alembic, while explicit `postgresql+psycopg2://` URLs keep working. Behind transaction-mode PgBouncer below 1.21, set `CHAT_HISTORY_DB_DISABLE_POOLING=true` (the chat-history engine then keeps psycopg 3 statements unnamed) or run PgBouncer 1.21+ in `session` mode.
