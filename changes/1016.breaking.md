Removed the Agent Portal: the `/agent-portal` UI, the `atlas-portal` CLI, the `/api/agent-portal/*` routes, the host-process manager, and their settings, tests and docs are gone. If you had `FEATURE_AGENT_PORTAL_ENABLED`, `AGENT_PORTAL_ALLOWED_ORIGINS`, `AGENT_PORTAL_DB_URL` or `AGENT_PORTAL_AUDIT_PATH` set, they are now ignored (a one-time startup warning notes this) and can be deleted. Leftover data at `data/agent_portal.db`, `data/agent_portal_audit.jsonl` and `<APP_CONFIG_DIR>/agent_portal_presets.json` is no longer read and can also be removed.
