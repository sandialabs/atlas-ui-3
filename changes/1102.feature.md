Selecting data sources now turns the built-in `atlas_search` tool on for you. The tool panels show it as enabled with the note "Automatically enabled by selected data sources." and it cannot be switched off while sources are selected; deselecting every source removes it again. The model is offered the tool rather than forced to call it, and the "your data sources were not searched" warning is replaced by a one-line notice that only appears when the search tool really cannot run.

Security note: because a selected source now implies the search tool, a turn that carries a source *and* a tool from an MCP server can read the internal corpus and hand what it read to that server in the same turn. Deployments that do not want that can set `FEATURE_ATLAS_SEARCH_WITH_OUTBOUND_TOOLS=false` (the orchestrator then keeps the implied tool out of such turns) or install the reference hook that does the same. The tool's own access rules, the per-source classification checks and the outbound approval gate are unchanged.
