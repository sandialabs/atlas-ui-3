Chat history now connects to PostgreSQL with the psycopg 3 driver on every install path: bare `postgresql://` URLs are normalized to `postgresql+psycopg://` before any SQLAlchemy engine is created (app and Alembic migrations), and SQLAlchemy is required at 2.1+, whose default driver is also psycopg 3 — lockfile installs that previously resolved bare URLs to psycopg2 move to psycopg 3. `CHAT_HISTORY_DB_DISABLE_POOLING=true` now also disables psycopg 3 statement auto-prepare, so transaction-mode PgBouncer keeps working.
