LiteLLM team gateways: an entry in a gateway's `models` allowlist may set any field `model_defaults` may (`supports_tools`, `supports_vision`, `supports_pdf`, `max_tokens`, ...), so one gateway can offer models with different capabilities; the model picker and the chat's file and tool controls follow the selected model.

An unknown field in a gateway's `model_defaults` is now refused when the config loads, as in a `models` entry, instead of being silently ignored; check existing gateway configs for misspelt settings before upgrading.
