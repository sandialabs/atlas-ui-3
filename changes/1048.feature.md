LiteLLM team gateways: an entry in a gateway's `models` allowlist may set any field `model_defaults` may (`supports_tools`, `supports_vision`, `supports_pdf`, `max_tokens`, ...), so one gateway can offer models with different capabilities; the model picker and the chat's file and tool controls follow the selected model. With compliance levels on, the model list's rows now show each model's levels, as a gateway's model rows already did.
