Parallel conversation runs now record their own outcome. When a second chat was started while an earlier run was still working, the earlier run's final status was taken from the newer turn: a run that died on a rate limit or timeout showed as finished (no "Failed" badge in the history list), and a run that finished cleanly could show as "Failed" with the other run's error. Each run now keeps the result of its own turn, in the live status and in the snapshot a reconnecting browser receives.
