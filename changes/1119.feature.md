Import all 53 MIT-licensed Retro Design System themes as a build-time Atlas catalog with scoped original tokens, accessible previews and search, era-specific window/button/input chrome across all 53 designs, and persistent selection alongside the existing Light and Dark modes. Preserve compatibility with the initial Mac System 7, Windows 95, and CRT presets; no external artwork or runtime renderers are bundled. Add persistent theme favorites and a keyboard-accessible path back to filtered-out active selections. Gate the catalog behind a build-time flag (`VITE_FEATURE_RETRO_THEMES`, default on; off ships only Light and Dark) and a run-time flag (`FEATURE_RETRO_THEMES_ENABLED`, default off, exposed as `features.retro_themes`); when either is off a saved retro theme renders as its base Light or Dark mode from first paint and is restored when re-enabled. Log, system, tool, approval and agent text now take theme-derived AA tones, and the browser contrast check measures the real React components (rest and hover, gradients, transparency and full-cover pseudo-elements composited, unmeasurable surfaces listed). Composer warnings, toasts, error boxes and admin status pills use opaque generated notice tints that reach AA in every theme; LogViewer, Files, Telemetry, Admin, Help and Marketplace pages use the theme-aware ramp instead of light-first and OS `dark:` classes, and are measured by the same check, as are the chat-side panels (tool, prompt and workspace selectors, context meter, Tools tab, gateway model picker, canvas, elicitation and token dialogs, prompt manager and Settings error boxes) in their open and error states. The backend stamps the live run-time flag on the first-paint bootstrap tag, so flipping it never flashes the previous theme.
