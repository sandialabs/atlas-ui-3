The browser now holds a New Chat or conversation switch made while the WebSocket is down and re-sends it on reconnect until the server confirms it, tells the user when it cannot be confirmed, and no longer replays it after the login session ends. Reconnects back off when the upgrade is refused, retry as soon as the network or tab returns, ignore events from replaced sockets, and a dropped elicitation answer, Stop, agent answer or file attach is reported instead of silently lost.
