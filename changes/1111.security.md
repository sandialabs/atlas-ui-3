New `FEATURE_HEADER_AUTH_ENABLED` setting (default `true`). Set it to `false` with OIDC login enabled to run OIDC-only: the trusted identity header is then ignored on HTTP and WebSocket requests, even with a valid proxy secret, so it can no longer be used to bypass OIDC login. Startup fails if header auth is disabled and OIDC login is disabled or incompletely configured.
