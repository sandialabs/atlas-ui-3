`llmconfig.yml` can now list LiteLLM gateways above static models in the model picker (`model_picker_order: gateways_first`) and set a starting model: a top-level `default_model`, or a gateway's `default_team` and `default_model`. A new session starts on the gateway default only when the user is in that team and the team offers the model; otherwise it falls back to the next default.
