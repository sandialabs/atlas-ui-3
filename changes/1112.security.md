Removed MCP sampling and centralized MCP authorization so tools, prompts, and resources all enforce the same user, group, data-classification, and per-model checks. Unauthorized users can no longer retrieve prompts from restricted MCP servers.

Operators must remove `tool_planner` and `sampling_demo` server entries from custom `mcp.json` files, and any MCP server that calls `ctx.sample()` will now receive an error instead of an LLM response.
