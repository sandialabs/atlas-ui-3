Multi-replica deployments (Redis) now detect a lost replica: each agent run holds an ownership lease, and when the replica running it crashes or freezes another replica reports the run failed with `interrupted: true`, keeping completed tool output and never replaying a tool. A replica that lost its lease is fenced out of shared run state, `GET /api/agent-runs/{id}` answers on any replica, and `RUN_LEASE_SECONDS` (default 30) tunes the lease (#1128).
