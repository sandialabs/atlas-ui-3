The package-level singletons `atlas.modules.mcp_tools.mcp_tool_manager` and `atlas.modules.llm.llm_caller` were removed; build or look up the runtime instances through the application factory instead (`from atlas.infrastructure.app_factory import app_factory`, then `app_factory.get_mcp_manager()` / `app_factory.get_llm_caller()`). A conversation's MCP sessions are now actually released when its last run finishes, so stateful MCP servers start each turn of a conversation with fresh sessions — state that must survive across turns belongs in the server's own durable store keyed by the conversation.
