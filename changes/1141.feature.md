Renamed the built-in sub-conversation tools so they read as delegating work to a subagent: `atlas_launch` is now `atlas_launch_subagent`, with `atlas_get_subagent_runs`, `atlas_get_subagent_result`, `atlas_follow_up_subagent` and `atlas_discover_subagent_options` alongside it, listed under a **Subagents** heading in the tools panel and titled "Launch Subagent", "Get Subagent Result" and so on in the transcript. The old names remain callable as deprecated aliases (tool calls, stored selections and hook matchers all still resolve), so existing agents and prompts keep working; hook scripts that compare built-in tool names themselves should add the new names.
