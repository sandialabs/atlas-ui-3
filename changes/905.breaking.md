MCP server authors: on a FastMCP 4 server, `ctx.elicit()` and connection-scoped `ctx.get_state`/`ctx.set_state` no longer work for Atlas connections, because MCP `2026-07-28` has no server-initiated requests or sessions. Return an `InputRequiredResult` (see `atlas/mcp_shared/user_input.py`) and use explicit sessions instead; the bundled `elicitation_demo`, `session_state_demo` and `task_demo` show how. Tools declared task-`required` on a FastMCP 3 server cannot be called until that server is upgraded.
