Added an opt-in agent-runs REST API (`/api/agent-runs`) that lets one trusted service, authenticated by a master `AGENT_RUNS_API_KEY`, launch, poll, follow up and cancel agent runs on behalf of any user; runs reuse the `atlas_launch` admission path, appear as top-level conversations in the user's history, never auto-approve admin-mandated tools, and support idempotent retries. Enable with `FEATURE_AGENT_RUNS_API_ENABLED=true`; see `docs/admin/agent-runs-api.md`.
