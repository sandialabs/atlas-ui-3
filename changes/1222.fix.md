A parent conversation can read its sub-conversations from any replica: `atlas_get_subagent_runs` and `atlas_get_subagent_result` now find children that are running on, or were launched by, another replica, and finished children after the run records expire or the server restarts, using the shared run records and the saved child conversations. A sub-conversation listed by a replica that does not own it keeps its parent, title and launch origin. Following up on a child (`atlas_follow_up_subagent`) still needs the replica that launched it.
